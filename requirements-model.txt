# RF-DETR, the transformer entry in other_models/models.py. Deliberately the BASE package
# and not rfdetr[train]: other_models/engine.py runs the training loop itself (so that the
# recipe is ultralytics', not Roboflow's), and all we take from rfdetr is the nn.Module,
# the SetCriterion and the COCO-pretrained weights. The [train] extra would additionally
# pull pytorch-lightning, torchmetrics, pycocotools, roboflow and ~8 more, none of which is
# used. `import rfdetr` is lazy about lightning, so the base install reaches everything we
# need. Brings transformers (the DINOv2 backbone), supervision, pydantic and tokenizers.
#
# Pinned to the 1.11 minor on purpose. rfdetr_adapter.py depends on structural and
# semi-private API -- LWDETR._get_backbone_encoder_layers(), the net.backbone[0].encoder
# layout, the encoder.embeddings.* parameter names, PostProcess(num_select=,
# upsample_masks_to_image_size=) and build_criterion_from_config's signature -- so an open
# upper bound invites either a loud RuntimeError or, worse, a silently unfrozen backbone
# while args.yaml still claims one trainable block.
rfdetr>=1.11.2,<1.12
